# QA Governance

Every Claude Code delivery must include:

- Completed requirements
- Remaining requirements
- Known issues
- Assumptions
- Test evidence
- Change log

QA checklist:

✓ Requirements implemented
✓ Acceptance criteria passed
✓ No broken formulas
✓ No duplicate IDs
✓ Calendar sync tested
✓ AI disabled mode tested
✓ AI enabled mode tested
✓ Error logging verified
