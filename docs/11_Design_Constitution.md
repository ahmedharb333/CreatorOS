# CreatorOS Design Constitution

## Core Principles

1. Execution over organization.
2. Every feature must reduce creator friction.
3. Enter data once; reuse everywhere.
4. AI recommends; users approve.
5. Capacity before ambition.
6. Missed work is recovered, not hidden.
7. Production is planned before publishing.
8. Every record has a permanent ID.
9. Every automation is explainable.
10. Core workflows work without AI.

## Product Test

Before adding any feature ask:

- Does it help creators publish more consistently?
- Does it reduce manual work?
- Can it be understood in under five minutes?
- Can it be maintained inside Google Sheets?

If "No", defer it.
